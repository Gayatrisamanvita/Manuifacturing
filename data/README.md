# Data Directory

Please drop your dataset file(s) here!

### Accepted formats:
- `.csv`, `.xlsx`, `.parquet`, `.json`

### Organization options:
1. **Single file / Combined data**: Drop directly into this folder (`data/`).
2. **Multiple files by tier**:
   - `data/manufacturing/` (shift logs, machine telemetry, station defects, sensor drifts)
   - `data/raw_materials/` (receiving inspection, batch measurements, material specs)
   - `data/supplier/` (vendor batch records, historical quality, warranty/field claims)

Once you have placed the files here, let me know their file names (or just say you're ready), and I will inspect the schema, profile the data, and build the end-to-end models answering all 11 questions.
