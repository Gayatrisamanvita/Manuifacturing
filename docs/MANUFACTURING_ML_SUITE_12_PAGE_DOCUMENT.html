3. Theoretical Research Grounds: Metallurgical Physics

Manufacturing defects cannot be addressed by purely statistical heuristics. Quality models must incorporate continuum mechanics, metallurgical dislocation theory, and fastener friction dynamics.

Vickers Hardness (HV) Indentation Mechanics
The Vickers test applies a square-base diamond pyramid indenter with a 136° apical face angle under test load F (kgf):
HV = (2 * F * sin(136° / 2)) / d² ≈ 1.8544 * (F / d²)
where d is the arithmetic mean diagonal length of the resulting permanent indentation in millimeters.

Tensile Strength & Yield Drift

For medium-carbon structural alloy steels (AISI 4140, Grade 10.9), Ultimate Tensile Strength ($R_m$) scales monotonically with core hardness:

R_m ≈ 3.25 * HV [MPa]
// At nominal 205.0 HV : R_m = 666.2 MPa (Optimal ductility, A5 > 16%)
// At marginal 227.3 HV : R_m = 738.7 MPa (High yield, embrittlement, A5 < 9%)

Fastener Tightening Kinematics: Kellermann-Klein Formulation

According to the VDI 2230 standard, the total tightening torque ($T$) applied by an automated nutrunner resolves into thread friction torque ($T_{th}$), underhead friction torque ($T_b$), and elastic bolt pre-load elongation ($T_{pitch}$):

T = F_M * [ 0.5 * d_2 * tan(phi + rho') + 0.5 * d_head * mu_head ]
where:
F_M = Clamping pre-load force generated in the joint (N)
d_2 = Thread pitch diameter; phi = Lead angle = arctan(P / (pi * d_2))
rho' = Apparent friction angle = arctan(mu_thread / cos(alpha / 2))
mu_head = Underhead bearing friction coefficient (~0.12 - 0.18)

Under nominal material hardness ($205\text{ HV}$), approximately **$88\%$** of applied torque is dissipated overcoming friction, while **$12\%$** generates clamping force. When hardness drifts past **$216\text{ HV}$**, thread shearing increases, prematurely triggering torque shutoff before target pre-load is attained.

3.3 Statistical Process Control (SPC) & Reliability Theory

Statistical Process Control establishes upper and lower specification limits based on normal distribution dispersion. However, traditional SPC fails when distributions exhibit severe kurtosis or multi-modal supplier mixes.

Process Capability Indices: Cp vs. Cpk

C_p = (USL - LSL) / (6 * sigma)
C_pk = min( (USL - mu) / (3 * sigma), (mu - LSL) / (3 * sigma) )
// Empirical Baseline at Receiving QC:
// LSL = 180.0 HV, USL = 230.0 HV, mu = 207.8 HV, sigma = 7.92 HV
C_p = 1.052, C_pk = 0.934 (Defect-generating capability < 1.00)

Game-Theoretic Shapley Value Attribution (TreeSHAP)

Shapley values calculate the marginal contribution of feature $i$ across all possible feature subsets $S \subseteq N \setminus \{i\}$:

phi_i(v) = sum_{S subseteq N \ {i}} [ |S|! * (|N| - |S| - 1)! / |N|! ] * [ v(S U {i}) - v(S) ]

TreeSHAP calculates exact attributions in polynomial time $\mathcal{O}(TLD^2)$, providing instantaneous explanation of whether high spindle temperature ($+7.35\text{ SHAP}$) or torque status ($+1.26\text{ SHAP}$) triggered the failure prediction.

Weibull Reliability & Warranty Hazard Modeling

Field warranty failures follow a two-parameter Weibull probability density function:

f(t) = (beta / eta) * (t / eta)^(beta - 1) * exp( - (t / eta)^beta )
h(t) = (beta / eta) * (t / eta)^(beta - 1) // Hazard Rate Function

Empirical fitting on the warranty dataset yields a shape parameter $\beta = 0.68 < 1.0$, mathematically proving **infant mortality**. Field failures are not customer wear-out incidents; they are direct manufacturing escapes stemming from factory fastening stalls.

Standard machine learning models trained strictly on raw sensor readings fail to capture non-linear electro-mechanical interactions. The FeatureEngineering module (src/features.py) derives domain-specific kinetic and thermal variables.

Engineered Feature Mathematical Formulation Physical & Quality Significance

Tool Stress Factor S_tool = Tool_Wear * Vibration_RMS Identifies harmonic chattering caused by worn screwdriver bit flutes.
Thermal Dissipation Index Psi_th = Spindle_Temp * Vibration_RMS Detects bearing failure and frictional heating during high-load runs.
Hydraulic-Thermal Ratio Phi_hyd = System_Pressure / (Spindle_Temp) Monitors fluid breakdown and pressure drops in clamping cylinders.

Outlier Sanitization & Boundary Enforcement

Raw analog sensors frequently encounter transient noise spikes. Data sanitization enforces physical bounding boxes: Spindle Temp [$30^\circ\text{C}, 130^\circ\text{C}$], Vibration [$0.1\text{g}, 6.0\text{g}$], Pressure [$60, 200\text{ PSI}$]. Outliers exceeding 4 times the Interquartile Range (IQR) are flagged and clamped using winsorization to prevent gradient explosion during tree splitting.
